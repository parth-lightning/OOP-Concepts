# OOP-Concepts

Welcome to the **OOP-Concepts** repository!  
This repo is dedicated to capturing, documenting, and practicing Object-Oriented Programming (OOP) concepts as I learn them in class.

## Purpose

- **Learning Archive:** Track all OOP concepts and principles covered in coursework.
- **Code Practice:** Implement examples and exercises for each concept.
- **Reference:** Serve as a quick reference for OOP topics and their code implementations.

## What to Expect

- Concepts such as Classes, Objects, Inheritance, Polymorphism, Abstraction, Encapsulation, etc.
- Sample code and explanations for each topic.
- Notes and summaries from class lectures.
- Incremental updates as new concepts are learned.

## How to Use

- Browse the repo for folders/files dedicated to individual OOP topics.
- Read the markdown notes and review the code samples.
- Feel free to fork, clone, or contribute if you find the material useful.
- I am currently using Turbo C++ for practising my OOP Concepts.
